## Каталог
Товары лежат в массиве `PRODUCTS` в начале `script.js`: фото, название, цена (`null` означает «Цена в WhatsApp»), категория и флаг «новинка». Кнопка на карточке открывает WhatsApp с готовым сообщением о товаре. Фильтры работают, плитки коллекций открывают каталог с нужным фильтром.

## Скорость
- Фото загружаются, только когда до них доскроллили; главное фото подгружается заранее (preload).
- Карта 2ГИС подключается, только когда до неё доскроллили.
- Заставка держится 0,35 с и не ждёт загрузки всех картинок.
- Блоки ниже первого экрана не отрисовываются, пока не нужны (`content-visibility`).

## Что ещё не сделано

- Регистрация и вход: кнопки неактивны (disabled), подписаны «скоро».
